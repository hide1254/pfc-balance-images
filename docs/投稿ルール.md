# おむすび先生（@pfc_balance2026）投稿ルール

> この保管庫の投稿は、すべてこのルールで作る。Claude が原稿を作るときも、この順で確かめる。
> 最終更新：2026-10-21

## 1. 誰に向けて
- **女性全般**（産後に限らない）。忙しくて、自分の食事が後回しになりがちな人
- 「がんばっているのに…」「私だけ？」という気持ちに寄り添う

## 2. 1枚目（表紙）
- **専用の表紙テンプレート**（make_cover.py）で作る。NotebookLM の図解は使わない
  - 大きな2行の言葉／シリーズの色／「保存版」「○×クイズ」などの印／「こんな人へ」の一言／「全5枚 →」／おむすび先生
  - 半分以上の人は1枚目しか見ない。小さく表示されても読める大きさにする
- **読む人の悩み・疑問から入る**。説明から入らない
  - ✕「炭水化物ってなに？」 → ○「糖質オフで減った体重、実は…？」
- 20字前後。2行で読み切れる長さ
- 「痩せる」「燃える」など効果を言い切る言葉は使わない（疑問の形でも乱用しない）

## 3. 2〜5枚目（中身は「実用」を多めに）
- 「〇〇とは」より「今日何を食べる？」：コンビニの組み合わせ、置き換え、簡単メニュー例を増やす
- 1枚に伝えることは1つ。箇条書きは3つまで
- 最後の1枚は「今日からできること」か「まとめ」。保存したくなる形に
- 体の不調の回は、最後に「つらい症状が続くときには、無理せずに医療機関に相談してくださいね」

### 3-2. 「気になる」をつくる型（2026-10-23 本人：どんどんアップグレードする）
- 毎回、次の型のうち **2つ以上** を入れる
  1. **意外な事実**：「えっ、そうなの？」となる一言（資料にあることだけ）
  2. **やりがち → おすすめ**：よくある選び方と、代わりの選び方を並べる（事実にもとづく比較）
  3. **買える物の名前**：コンビニ・スーパーで手に取れる食材やお惣菜の名前
  4. **組み合わせ例**：「〇〇＋〇〇＋〇〇」の形で、そのまま真似できる
  5. **自分ごとチェック**：「こんな日ありませんか？」で読む人の場面から入る
- 「〇〇とは」「〇〇のまとめ」だけの見出しにしない。見出しだけで中身が分かる言葉にする
- 不安をあおる・効果を言い切る、はこれまでどおり使わない
- インスタの数字（保存・リーチ）が集まったら、伸びた型を増やす

## 4. キャプション
- **1行目は表紙と同じ言葉**（フィードで最初に見える所）。2行目に【保存版】【○×クイズ】【今週のおさらい】
- 共感 → 中身 → 今日からの一歩 → **呼びかけは「保存」の1つだけ**（呼びかけを並べると、全部無視されやすい）
- 250字前後

## 5. ハッシュタグ（10〜11個）
- テーマの言葉を3つ ＋ 共通の8つ
- 共通：#ダイエット #ダイエット女子 #大人女子 #食事改善 #栄養バランス #ダイエットごはん #ゆるダイエット #おむすび先生
- 「#痩せる」など効果をうたう言葉は使わない

## 6. 書き方の決まり（分身パック 03_voice より）
- 確かめにくい数字は使わず、「ずっと多い」など言葉で伝える
- 専門家でも意見が分かれる話は外さず、「私はこう考えています」と書く
- 効果の言い切り・医療の話（病気の予防・治療）は書かない
- 人を責めない・不安をあおらない

## 7. 画像
- NotebookLM の図解（正方形・editorial・水彩風）＋ 下におむすび先生の帯（1080×1350）
- 人物は描かない。食材にも顔を描かない。薬・サプリ・元素記号の絵は入れない
- 5枚を目で確かめる（誤字・顔・薬の絵・「私は考えています」の抜け）
- 同じ5枚から、リール用の縦長動画（1080×1920・約14秒）も作る。**最初の画面は表紙の大きな言葉**（最初の3秒が勝負）

## 8. 使わない資料
- 「炭水化物の取り方」（無断引用・転載禁止の記載）／「8日目血液解析」（医師法）／「症例１」（お客さんの情報）
- 腸活365アカデミーの会員資料（院外での利用は規約で不可）
